# Open-Source Rights Authorization Record

Status: **由仓库根目录的规范记录决定；当前仍待项目所有者批准**

This is the human authorization gate for an Auris Flow public release. An
automated check can prove that the Apache License 2.0 text is present; it cannot
prove that the repository has authority to grant those rights.

## Canonical authorization record

The only machine-checked authorization record is
[`open-source-rights-authorization.md`](../../open-source-rights-authorization.md).
Complete that file together with `NOTICE`; do not maintain a second set of names,
dates or approval references in this report. The canonical record requires a legal
rights-holder name, approved copyright notice, UTC approval date, immutable evidence
reference and SHA-256 digest, Apache-2.0 authorization and explicit final-NOTICE
confirmation.

## Acceptance rule

Until the canonical record is complete and linked from immutable approval evidence,
maintainers must not tag, publish, sign, or describe the repository as a completed
formal open-source release. The placeholder line in `NOTICE` must be replaced with
the approved notice in the same release candidate commit.

If ownership is shared or any contribution has a different rights holder, add a
separate signed authorization or provenance record for each holder before
release.
