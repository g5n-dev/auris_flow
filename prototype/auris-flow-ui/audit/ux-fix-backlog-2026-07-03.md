# Auris Flow UX 修复 Backlog

日期：2026-07-03

原则：不重构 `App.tsx` 大结构，不替换主导航、顶部栏、模块划分和页面层级；只做局部、可解释、可回滚的增强。

## 1. 术语清理：隐藏底层执行名词

优先级：P1

涉及文件：

- `src/App.tsx`

修改点：

- 将前台可见的 `Dagster` 替换为“执行引擎 / 执行映射 / 资产物化 / 调度对象”。
- 将 `DAG` 替换为“编排图 / 依赖图 / 流程快照”。
- 将 `mock run record / mock ledger / mock 草稿` 替换为“演示运行记录 / 本地记录 / 草稿记录”。
- 将“任务画布”按语境替换为“任务配置 / 编排视图 / 流程视图”。
- 保留底层字段时，放入“高级执行映射”折叠面板。

验收：

- 主页面不可见 `Dagster`、`DAG`、`mock`。
- 技术字段只在高级详情或开发辅助区域出现。

## 2. 知识可视化：从数据视图改为知识图谱/消费路径

优先级：P1

涉及文件：

- `src/App.tsx`
- `src/styles.css`

修改点：

- 保留“知识可视化”tab。
- 主体改为 `source -> chunk -> entity/tag -> index -> app` 五列图谱。
- 每条边展示数量、质量状态、最近版本。
- 节点点击后右侧或下方展示：来源、证据、召回效果、依赖任务。
- 删除或下沉“当前数据视图”“清空 / 导出当前数据”的表格主导语言。

验收：

- 一眼能看出知识如何从来源进入索引，并被业务场景消费。
- 没有大块空白。
- 至少有 3 类知识源、3 类知识对象、3 类消费场景。

## 3. 洞察 tab 去同质化

优先级：P1

涉及文件：

- `src/App.tsx`
- `src/styles.css`

修改点：

- 业务大盘：加入可配置指标卡、趋势曲线、运营漏斗。
- 门店归因：加入门店 -> 标签 -> 业务动作的桑吉图或路径图。
- 销售绩效：加入人员/门店转化漏斗和排名。
- 标签资产：保留标签资产 BI，但补齐右侧证据可视区域，不能留白。
- 模型质量：ASR/VAD/说话人/标签模型质量趋势和雷达。
- 报告中心：报告列表、订阅状态、发送记录、回写结果。

验收：

- `audit/tab-similarity.json` 中洞察任意两个 tab 相似度低于 0.65。
- 每个 tab 至少有一个独有图表或独有操作闭环。

## 4. 任务触发与调度业务化

优先级：P1

涉及文件：

- `src/App.tsx`

修改点：

- 主面板展示：触发方式、生效范围、并发、重试、回填、下次运行。
- “设置定时”按钮打开轻量弹窗或右侧配置区。
- `ScheduleDefinition / SensorDefinition / RunRequest / BackfillPolicy` 下沉到高级执行映射。
- 设置成功后追加运行/配置记录。

验收：

- 用户不用理解底层调度对象也能完成“定时跑一次/每日跑/数据到达触发/回填”。

## 5. 设置 tab 内容差异化

优先级：P1

涉及文件：

- `src/App.tsx`

修改点：

- 模型配置、工具配置、阈值配置、权限配置、存储配置、通知配置各自有独立字段。
- 不再复用同一套卡片标题和同一批记录。
- 每个 tab 保留“保存草稿 / 校验 / 发布 / 审批记录”的一致操作。

验收：

- `audit/tab-similarity.json` 中设置任意两个 tab 相似度低于 0.7。

## 6. 调听工作台控件分组和可读性

优先级：P2

涉及文件：

- `src/App.tsx`
- `src/styles.css`

修改点：

- 播放控制、定位控制、标注模式分组。
- 数字按钮补单位和 tooltip：`退 5s`、`进 5s`、`窗口 30s`。
- 轨道标签只显示短标签，完整信息在 hover 或右侧详情。
- 右侧 Agent 建议区减少空白，展示证据、冲突、下一步动作。

验收：

- 不再出现多个含义不明的 `5 / 30 / 5s` 按钮。
- 右侧建议区没有大块无内容留白。

## 7. 资产页语言收敛

优先级：P2

涉及文件：

- `src/App.tsx`

修改点：

- 资产页主文案只讲业务资产、血缘、质量、回填、导出。
- 底层执行定义放入“执行映射”。
- 资产卡片增加“来源任务 / 最近物化 / 下游消费 / 质量状态”。

验收：

- 业务用户可以理解资产页是“管理可复用产物”，不是调试执行引擎。

## 8. 全局/局部动作去重

优先级：P2

涉及文件：

- `src/App.tsx`

修改点：

- 全局：搜索、筛选、导出只处理当前模块范围。
- 局部：当前对象动作必须带对象语义，例如“导出证据包”“导出效果报告”“同步当前索引”。
- 同名 tab 和右侧 tab 增加上下文：任务运行记录、节点运行记录。

验收：

- 自动诊断中关键页面 `duplicateButtons` 明显减少。

## 9. 关键数字口径补齐

优先级：P2

涉及文件：

- `src/App.tsx`

修改点：

- KPI 小字统一说明：范围、时间、版本、对象类型。
- 洞察、知识、资产之间的数字必须说明关系。

验收：

- 用户不会把知识对象数、标签样本数、报告数、资产数混为同一口径。

## 10. 声纹粒子视觉降遮挡

优先级：P3

涉及文件：

- `src/App.tsx`
- `src/styles.css`

修改点：

- 中心质量评分浮层移到右上或侧边摘要。
- 背景粒子/向量维度保留，但不遮挡波形和质量维度。
- 增加播放态：当前 wav、声纹片段、质量维度同步高亮。

验收：

- 既有声纹科技感，又不遮挡主要质量评分和入库动作。
